# Titanic Survival Classification

Kaggle getting-started competition. Explores feature engineering and model selection
with MLflow experiment tracking and an interactive Plotly EDA notebook in Emacs org-mode.

## Project layout

```
titanic/
  data/           train.csv, test.csv (download via Kaggle CLI)
  plots/          Plotly HTML charts (generated by eda.org)
  submissions/    Final submission CSVs (generated by submit.py)
  mlruns/         MLflow tracking data (generated by train.py)
  eda.org         EDA notebook (Emacs org-babel + Plotly)
  features.py     Feature engineering module
  train.py        Model training with MLflow tracking
  submit.py       Generate submission from best MLflow run
```

## Setup

### 1. Install dependencies

```bash
pip install pandas numpy scikit-learn mlflow plotly xgboost lightgbm kaggle
```

### 2. Download data

Get your API token from kaggle.com → Account → API → "Create New Token", then:

```bash
mkdir -p ~/.kaggle
mv ~/Downloads/kaggle.json ~/.kaggle/
chmod 600 ~/.kaggle/kaggle.json

kaggle competitions download -c titanic -p data/
unzip data/titanic.zip -d data/
```

You must accept the competition rules on Kaggle before the download will work.

### 3. Emacs ob-python (once per machine)

Add to your `init.el` if `ob-python` is not already enabled:

```elisp
(org-babel-do-load-languages 'org-babel-load-languages '((python . t)))
(setq org-babel-python-command "python3")
(setq org-confirm-babel-evaluate nil)
```

## Running the pipeline

```bash
# 1. Verify feature engineering
python features.py

# 2. Train all models (5 models × 3 feature sets + voting ensemble)
#    Results logged to mlruns/ automatically
python train.py

# 3. Inspect results in MLflow UI
mlflow ui   # open http://127.0.0.1:5000

# 4. Generate submission from the best run
python submit.py
```

The submission CSV lands in `submissions/submission_<run_id>.csv` and is ready to upload at
kaggle.com/c/titanic.

## EDA notebook

Open `eda.org` in Emacs. Each `#+begin_src python` block runs with `C-c C-c`. Plot blocks
save an interactive HTML file and return an org link — press `C-c C-o` on the link to open
it in your browser.

Sections covered:

- Missing values
- Survival overview
- Age and fare distributions
- Survival rate by sex, passenger class, and port of embarkation
- Sex × class interaction
- Feature correlations
- Engineered features: title, family size, age group
- Random forest feature importance

## Feature engineering (`features.py`)

`build_features(df, encoder, fit)` transforms a raw DataFrame and returns `(X, feature_cols, encoder)`.

| Feature | Description |
|---|---|
| `Title` | Extracted from Name (Mr, Mrs, Miss, Master, Rare) |
| `FamilySize` | SibSp + Parch + 1 |
| `IsAlone` | 1 if FamilySize == 1 |
| `HasCabin` | 1 if Cabin is not null |
| `Deck` | First letter of Cabin (U if unknown) |
| `TicketFreq` | Number of passengers sharing the same ticket |
| `AgeGroup` | Age binned into Child / Teen / Adult / Middle / Senior |
| `FareBand` | Fare quartile (Q1–Q4) |

Pass the fitted encoder from training to `build_features(test_df, encoder=enc, fit=False)` to
apply the same transformation to the test set.

## Models tracked in MLflow

Each model is trained across three feature sets (`baseline`, `engineered`, `reduced`) and
logged as a separate run.

| Model | Class |
|---|---|
| Logistic Regression | `sklearn.linear_model.LogisticRegression` |
| Random Forest | `sklearn.ensemble.RandomForestClassifier` |
| Gradient Boosting | `sklearn.ensemble.GradientBoostingClassifier` |
| XGBoost | `xgboost.XGBClassifier` |
| LightGBM | `lightgbm.LGBMClassifier` |
| Voting Ensemble | Top-3 models by CV accuracy, soft voting |

Metrics logged per run: `cv_accuracy`, `cv_std`, `cv_auc` (5-fold stratified cross-validation).
